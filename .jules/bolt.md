## 2024-05-18 - [Fix InputArea re-render and MessageType id type conflict]
**Learning:** In React, passing non-memoized functions down to child components that heavily rely on state or context updates causes unnecessary re-renders of the child components, even if wrapped in React.memo. Additionally, mismatch in TS types between a globally defined interface (like in vite-env.d.ts) and a locally defined class sharing the same name leads to TS2719 conflicts when arrays of those types are passed between components.
**Action:** Always wrap callback functions passed as props to memoized child components in `useCallback`. Furthermore, ensure type definitions for models are synchronized across files, particularly when migrating from numeric IDs to string UUIDs, and update prop types appropriately in all consuming components.

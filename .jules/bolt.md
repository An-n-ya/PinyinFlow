## 2024-05-24 - React Context/State Updates Breaking Memoization
**Learning:** In React, if a parent component updates frequently (e.g. `Chat.tsx` receiving constant stream of messages or TTS events), child components will re-render unnecessarily unless they are properly memoized and their props are stable references. If `useCallback` is not used in the parent component for the props passed down to memoized children, `React.memo` will fail to prevent re-renders because the function prop is re-created on every render.
**Action:** When working with components that manage high-frequency state updates like chat messages or audio playback events, always identify expensive child components (like `InputArea`), wrap them in `React.memo`, and meticulously ensure all passed props (like `onSendMessage`) are stabilized with `useCallback` or moved outside the component scope if they don't depend on state.

## 2024-05-24 - Optimizing React Parent-Child Rendering with Callbacks
**Learning:** In React components like `Chat` that frequently update state (e.g., streaming tokens, receiving TTS/Audio events), it's critical to isolate expensive or complex child components (like `InputArea`). However, just wrapping the child in `React.memo` is insufficient if the parent passes down inline functions or unmemoized callbacks. The parent will recreate these functions on every render, invalidating the child's `React.memo` check and causing unnecessary re-renders.
**Action:** When applying `React.memo` to a child component to prevent it from re-rendering due to frequent parent state updates, always ensure that any functions passed as props to the child are wrapped in `useCallback` within the parent. Check the dependency arrays of those `useCallback` hooks to ensure they do not depend on the frequently updating state itself.

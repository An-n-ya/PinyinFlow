## 2024-04-03 - Radix UI Tooltip on Disabled Buttons Accessibility Pattern
**Learning:** Tooltips do not display on natively disabled HTML buttons because disabled elements do not fire pointer events. When using Radix UI `TooltipTrigger asChild`, do NOT unconditionally wrap the button in a span, as this causes an accessibility regression where `aria-describedby` applies to the span instead of the active button. Instead, conditionally render: when disabled, wrap the disabled button in a focusable `<span>` (`tabIndex={0}`) inside the `TooltipTrigger`; when active, `TooltipTrigger asChild` must wrap the button directly. NEVER add `role="button"` to the wrapper span.
**Action:** When adding tooltips to buttons that can be disabled in this project's UI, always implement conditional wrapper rendering to maintain both visual tooltip functionality and proper screen reader associations.

## 2024-03-17 - Disabled Button Tooltip Focus & Render Strategy
**Learning:** Tooltips wrapped around natively disabled HTML elements (`disabled=true`) fail to register pointer events (hover/focus), preventing the tooltip from displaying. This impacts accessibility for users trying to understand why a button (like the Send button when input is empty) is disabled. Wrapping the disabled element in a `span` with `tabIndex={0}` correctly enables focus/hover events.
**Action:** When adding tooltips to buttons that can be disabled, always wrap the button in an event-receiving `<span tabIndex={isDisabled ? 0 : -1}>` and attach the `TooltipTrigger` to the `span`. Ensure layout classes (like `absolute`) are transferred from the button to the `span` to preserve visual positioning.

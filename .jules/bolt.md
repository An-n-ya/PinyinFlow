## 2024-04-21 - InputArea Component Memoization
**Learning:** In the chat interface architecture, frequent backend events (like `tts-finished` and `audio-played`) cause rapid updates to the `messages` array state in the parent `Chat` component. Without memoization, this forces a re-render of the entire `Chat` component on every event, which subsequently passes a newly recreated `submit_pinyin` callback to the expensive `InputArea` child component, resulting in unnecessary, cascading re-renders of the input form.
**Action:** When a parent component receives high-frequency updates, identify static or infrequently-changing child components (like input forms) and wrap them in `React.memo`. Concurrently, ensure any callbacks passed as props to these children are stabilized using `useCallback` (and its dependencies are also stabilized) to ensure the memoization works as expected.
